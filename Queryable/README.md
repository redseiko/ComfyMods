# Queryable

*Query world files.*

## Commands

### In-Game

Run these commands in-game with the target world loaded.

  * `dump-items`
  * `dump-zdos`

### FejdStartup

Run these commands at `FejdStartup` and specify the target world (use tab to cycle worlds).

  * `dump-world-items <world-name>`
  * `dump-world-zdos <world-name>`

Note that custom prefabs are loaded (usually by JVL) only in-game so those prefab-names will be `NULL` when dumped.
